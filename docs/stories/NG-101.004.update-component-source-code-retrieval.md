# Story NG-101.004: Update Component Source Code Retrieval

## Status
Draft

## Story
**As a** Angular developer,  
**I want** to retrieve Spartan NG component source code,  
**so that** I can examine and use Angular component implementations in my projects.

## Acceptance Criteria
1. Source retrieval tool fetches TypeScript (.ts), HTML (.html), CSS (.css), and SCSS (.scss) files
2. File content retrieval works for all component file types in Spartan NG structure
3. Component file organization reflects Angular component patterns
4. Source code responses include proper file type identification
5. Error handling for missing or inaccessible component files

### Data Models
**ComponentFile Interface** [Source: architecture/data-models-and-schema-changes.md#componentfile]:
- `fileName: string` - File name (e.g., "hlm-button.ts", "hlm-button.token.ts")
- `filePath: string` - Full repository path
- `fileType: AngularFileType` - Enum: 'component' | 'token' | 'index' | 'spec' | 'stories'
- `content: string` - File content from GitHub API
- `size: number` - File size in bytes
- `lastModified: Date` - Last modification timestamp

**ComponentFileResponse Interface** [Source: architecture/api-design-and-integration.md#spartan_get_component]:
- `component: SpartanComponent` - Component metadata and information
- `files: ComponentFile[]` - Array of component source files with content
- `exports: string[]` - Public API exports from index.ts
- `dependencies: string[]` - Angular dependencies and peer dependencies

### API Specifications
**spartan_get_component Endpoint** [Source: architecture/api-design-and-integration.md#spartan_get_component]:
- **Request Schema**: `{ componentName: string, includeStories?: boolean, fileTypes?: string[] }`
- **Response Schema**: Component metadata with complete file structure and source code content
- **File Type Support**: TypeScript (.ts), token files (.token.ts), HTML (.html), CSS (.css), SCSS (.scss)
- **Repository Path**: Target `libs/helm/{component-name}/src/lib/` for component source files

**GitHub API Integration** [Source: architecture/external-api-integration.md#github-api-integration]:
- **Base URL**: `https://api.github.com/repos/spartan-ng/spartan`
- **Key Endpoints**: 
  - `GET /contents/libs/helm/{component-name}` - Get component directory structure
  - `GET /contents/libs/helm/{component-name}/src/lib/{file-name}` - Get component source files
- **Authentication**: GitHub Personal Access Token (existing pattern maintained)
- **Error Handling**: Rate limit handling, 404 handling, network timeout and retry logic

### Component Architecture
**SpartanRepositoryClient** [Source: architecture/component-architecture.md#spartanrepositoryclient]:
- `getComponentFiles(componentName: string): Promise<ComponentFile[]>` - Fetch component source files
- `getComponentStory(componentName: string): Promise<ComponentStory | null>` - Fetch associated story
- `getDirectoryStructure(path: string): Promise<DirectoryNode[]>` - Browse repository structure
- `getCachedContent(path: string): Promise<string | null>` - Check cache before API calls

**ComponentSchemaValidator** [Source: architecture/component-architecture.md#componentschemavalidator]:
- `validateComponentFile(content: string, fileType: AngularFileType): ValidationResult` - Validate individual files
- `validateComponentStructure(component: SpartanComponent): ValidationResult` - Validate complete component
- `extractComponentMetadata(indexFile: string): ComponentMetadata` - Parse component exports
